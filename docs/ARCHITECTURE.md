# Architecture

JellyFace is the [Caelestia](https://github.com/caelestia-dots/shell) desktop shell (a Quickshell/QML
project written for Hyprland), ported to run on COSMIC.

```
JellyFace/
├── bin/jellyface            command line entry point
├── scripts/                 install, build, run (supervisor), COSMIC tweaks, record.sh, pam-host-check.sh, lib.sh
├── shell/                   patched Caelestia shell (QML + C++ plugin sources); see shell/UPSTREAM
├── tests/stability.sh       restart / crash / stress test suite
├── helpers/cosmic-ws/       C helper: COSMIC workspaces (ext-workspace-v1) -> JSON lines
├── assets/                  ghost logo
├── config/                  default shell.json, shell-tokens.json, scheme.json (greyscale palette)
├── patches/                 our changes to upstream as one patch (for rebasing onto newer Caelestia)
├── docs/                    this file
├── backups/                 backups of your COSMIC / JellyFace config (never deleted automatically)
├── logs/                    runtime and build logs (git-ignored)
├── .build/  .install/       generated by `jellyface build` (git-ignored, safe to delete and rebuild)
└── .env.local               per-machine overrides, e.g. JF_CONTAINER (git-ignored)
```

## How it runs

```
COSMIC session (Pop!_OS host)
   │  Wayland (wlr-layer-shell)
   ▼
distrobox container (Arch)  ── quickshell -p shell/  ──►  bar, dashboard, launcher, ...
   │                                  │
   │                                  └─ spawns helpers/cosmic-ws/wsd  ──►  COSMIC workspaces
   └─ shares $HOME, the Wayland socket and the system D-Bus with the host
```

The shell runs in an Arch container because Quickshell, the Qt 6 build and Caelestia's plugins are
packaged for Arch; the container shares the Wayland socket, so its windows appear on your COSMIC desktop.

## What was changed from upstream (patches/0001-cosmic-port.patch)

| Change | Why |
|---|---|
| `ContentWindow.qml`: `dragMaskPadding = 0` | The edge-drag input padding assumed Hyprland workspace data; on COSMIC it blocked clicks along every screen edge. |
| `ShellState.qml`: fall back to the first screen when no Hyprland monitor is known | Bar clicks (logo -> launcher) looked up the "focused monitor" via Hyprland and got `null`. |
| `services/CosmicWs.qml` + `CosmicWorkspaces.qml`, `Bar.qml` | Real COSMIC workspaces in the bar, via the `wsd` helper. |
| `SidebarButton.qml`, `ContentWindow.qml` (Escape shortcut, full-screen mask while a panel is open), `Interactions.qml` (click-outside-to-close) | "Click outside to close" uses `HyprlandFocusGrab`, which only exists on Hyprland; the bell button and Escape close the sidebar/session/launcher on COSMIC. |
| `Recorder.qml`, `cards/Record.qml`, `scripts/record.sh` | Caelestia records with `caelestia record` + gpu-screen-recorder; COSMIC has no wlr-screencopy and the recorder failed inside its sandbox, so the card opens Kooha instead. |
| `Interactions.qml` (launcher hover) | The launcher opens on hover at the bottom edge and closes when the cursor leaves. |
| `launcher/services/Apps.qml` | The launcher started apps inside the Arch container, where none of your desktop's apps exist; it now asks the host (`distrobox-host-exec gtk-launch <desktop id>`). |
| `assets/pam.d/passwd` (generated from `config/pam-passwd.tmpl`), `scripts/pam-host-check.sh` | The lock screen used `pam_unix` inside the container, whose account has an empty password, so any input unlocked it. It now checks the password on the host and fails closed. |
| `services/Colours.qml`, `scripts/theme.py` | Caelestia derives colours from the wallpaper with its own CLI (not installed here); `theme.py` replaces it: it matches the COSMIC wallpaper to a palette from `Color_Palette/` and writes `scheme.json`, which the shell reloads live. |
| `OsIcon.qml` | Ghost logo instead of the distro logo. |
| `WeatherTab.qml` | Hard-coded 840px minimum width lowered to 640px so the dashboard can be smaller. |

Configuration-only changes (no code) live in `config/`: greyscale colour scheme, square border corners,
background/wallpaper feature off, dashboard sizes, active-window popout off, Celsius.

## Moving to a newer Caelestia

`shell/UPSTREAM` records the upstream commit. To update: check out a newer upstream into a fresh directory,
apply `patches/0001-cosmic-port.patch` with `git apply --3way`, fix conflicts, replace `shell/`.
